# LLM Wiki workflow

This skill's workflow will be implemented after the core runtime exists.

Expected behavior:
1. Clarify the knowledge item or research task.
2. Prefer official documentation and primary sources for changing API details.
3. Separate verified facts, assumptions and unresolved questions.
4. Save notes only inside the active workspace or a user-approved wiki path.
5. Include source URLs and a checked date for time-sensitive facts.
6. Before overwriting or deleting existing notes, show a diff or request approval according to policy.

No network, filesystem write, or shell operation is implicitly authorized by this document.
